# STYLE GUIDE: Flutter Output Standards & Design Token Contracts

> **Master Aesthetic & Design Guide (Pillar: 02_Creative)**
> Enforces production-grade Flutter UI conventions, design tokens, and restrained aesthetics.

---

## 1. Generated Flutter Architecture Standards

All Dart code generated by `flutterin` must adhere to these structural laws:

1. **Feature-First Clean Architecture**:
   ```text
   lib/src/features/<feature_name>/
   ├── presentation/
   │   ├── controllers/   # Riverpod Notifiers (@riverpod)
   │   ├── screens/       # Top-level route screens
   │   └── widgets/       # Modular, reusable presentation widgets
   ├── domain/
   │   └── models/        # Freezed immutable entities
   └── data/
       ├── datasources/   # Remote & local API clients
       └── repositories/  # Repository implementations
   ```
2. **Widget Discipline**:
   - Extract any widget tree exceeding 40 lines into dedicated private or public widgets.
   - Prefer `const` constructors on every invariant widget.
   - Avoid monolithic `build()` methods with deep nested indentation.

---

## 2. Design Token Contracts

### A. Spacing & Sizing
- Strict 8pt spacing grid: `4px` (half), `8px` (base), `16px` (md), `24px` (lg), `32px` (xl).
- Margin & Padding must use named constants or extensions: `AppSpacing.sm`, `AppSpacing.md`.

### B. Color Tokens & Contrast
- Strict WCAG AA compliance (minimum 4.5:1 for normal body text, 3:1 for large display headers).
- Material 3 `ColorScheme` integration:
  - Surface: `colorScheme.surface`
  - OnSurface: `colorScheme.onSurface`
  - Primary: `colorScheme.primary`
- Zero ungrounded hardcoded hex values in presentation widgets. All colors must resolve from `Theme.of(context)`.

### C. Typography
- Standard font stack: Inter, Roboto, or Geist.
- Type scale mapping:
  - Display: 32px / 40px line-height, bold.
  - Headline: 24px / 32px line-height, semi-bold.
  - Body: 14px / 20px line-height, regular.
  - Caption: 12px / 16px line-height, medium.

---

## 3. Micro-Interactions & Restraint
- Avoid gratuitous bouncing animations or decorative AI visual tells.
- Use crisp 1px borders with subtle opacity (`Colors.black.withOpacity(0.08)` or `Colors.white.withOpacity(0.12)`).
- Provide explicit tactile feedback states: hover, focus, pressed, disabled.
